# 《批红》· 万历十年 —— 设计文档 v1

> 一句话：**你是一台注意力极其有限的机器，而整个帝国都在等你的那笔红。**

---

## 0. 设计内核：稀缺的不是钱，是注意力

《皇帝成长计划2》把你设计成一台**全能操作机**：月初点户部、点礼部、点工部，一格一格把国家经营起来。你什么都能做，只是手不够快。

真实的历史不是这样。万历十年，一个二十岁的年轻人坐在乾清宫，每天面对的是**几百本奏疏**。他不能种地、不能练兵、不能修河，他唯一能做的动作是：**看一份文书，写几个字，然后交给别人去办。**

所以本作的核心资源不是银两、不是兵力，是**每月能处理的奏疏数**。

- 你一个月能细看的奏疏：8～15 本（受"精力"和"朝会频次"约束）
- 实际进本的奏疏：60～200 本
- 剩下的怎么办？**留中**。留中的奏疏堆积起来，就是"壅滞"——帝国的血管开始堵。
- 崇祯就是被这个机制杀死的：不是他不想干，是他一天只有二十四个时辰。

于是游戏的核心玩法不是"勤政"，而是：**建立一套让别人替你干活、并且你能验证他们干没干的系统。** 这件事在历史上有个名字，叫**考成法**。张居正刚死，他的考成法还挂在墙上，而所有人都在等你废掉它。

这就是本作的第一个重大选择，也是整局游戏的骨架。

## 1. 与《皇帝成长计划2》的分野

| 维度 | 皇帝成长计划2 | 《批红》 |
|---|---|---|
| 时间粒度 | 一月 = 清晨/晌午/晚上/深夜四个时段，逐格点 | 一月 = 一个回合，你只处理文书与召对 |
| 你的身份 | 全能操作员，什么都能亲手干 | 决策者：批红、召对、廷推、特旨 |
| 臣子 | 属性面板（智慧 87 / 忠诚 65 / 野心 42） | 履历、科第、座师、籍贯、派系、言行。**没有忠诚度数值** |
| 数字 | 真实值直接摊在你面前 | 奏报值。真实值藏在系统里，两者有差 |
| 建设 | 点按钮，钱到活成 | 立项、派人、定期限、验收。**会走样、会烂尾、会反噬** |
| 目标 | 攻城略地、天下一统 | 史评。你死之后，《明史》怎么写你 |
| 失败 | 亡国 Game Over | 亡国只是其中一种。更常见的是"在位四十八年，天下无事，而事已不可为" |

一句话概括差异：**帝成 2 让你爽，本作让你累，但累得明白。**

## 2. 历史设定：万历十年六月二十日

> 万历十年六月二十日（1582 年 7 月 9 日），太师、吏部尚书、中极殿大学士张居正卒于京师，年五十七。
> 上震悼辍朝，赠上柱国，谥文忠。
> 十日前，他刚被加封太师——有明一代唯一一位生前受封此职的大臣。

你，朱翊钧，虚岁二十，在位十年，亲政第一日。

**开局时你手上的牌：**

| 资产 | 状态 |
|---|---|
| 太仓银库 | 库银充盈，粟可支十年。这是张居正留给你的嫁妆，也是他留给你的枷锁 |
| 太仆寺马价银 | 积金四百余万两（兵部系统的钱，你随时可以"借"） |
| 考成法 | 还在执行。百官恨之入骨，但政令"虽万里之外，朝下而夕奉行" |
| 一条鞭法 | 万历九年刚推行全国，赋役折银，账目还没理顺 |
| 清丈田亩 | 万历八年下令，尚未告竣。地方正在鸡飞狗跳 |
| 九边 | 戚继光镇蓟州、李成梁镇辽东，边境安静。但年例银已近四百万两，且年年加派 |
| 内廷 | 冯保掌司礼监兼东厂，你的"大伴"，也是张居正的同谋。他还在 |
| 后宫 | 李太后（生母）仍在，说话极有分量。皇长子朱常洛生于本年八月 |

**开局时你看不见的牌：**

- 半年之后（本年十二月），御史李植会劾冯保十二大罪。你会大喜过望，说"吾待此疏久矣"。
- 一年之后（万历十一年），你会抄张居正的家。张家老弱被封在府中饿死十七口，其中三个婴儿。他的长子张敬修会写下血书自缢。
- 同一年，辽东一个叫努尔哈赤的女真人，以祖、父留下的十三副遗甲起兵。
- 三十八年后，他会是压垮这个王朝的第一块石头——而那一年，你还在位。

**为什么选这个时点：**

1. **体制高度成熟**：内阁—六部—六科—都察院—抚按，一条完整的官僚流水线已经跑了一百多年。你不需要"建立制度"，你要在既有的机器上做微调——这比"白手起家"难得多，也有意思得多。
2. **一切都在临界点**：改革遗产还在、改革者已死；财政最好、也最脆弱；边境最安静、也最危险。你手上是一副好牌，但每张牌都有代价。
3. **你的权力是真实的、也是可疑的**：你终于亲政了，但你不知道哪些命令会真的被执行，哪些会变成一纸空文。
4. **有明确的"历史参考答案"**：真实历史给出了一条线（怠政、矿税、三大征、辽东崩盘）。你走的每一步，都可以和它对照。这是最残酷的成就感。

## 3. 核心循环

```
┌─────────────────────────── 一个月 ───────────────────────────┐
│                                                              │
│  ① 进本    通政司/司礼监把本月文书送到你案头（60～200 本）      │
│      ↓                                                       │
│  ② 筛选    你只有 8～15 个"细看"名额（精力）。其余：          │
│            · 交司礼监批红（按你的授权规则自动处理）            │
│            · 留中（不批，堆积，制造壅滞）                      │
│            · 发内阁再议                                       │
│      ↓                                                       │
│  ③ 批红    对细看的每一本，四选一：                            │
│            【依拟】照内阁票拟批                               │
│            【改拟】自己写处理意见（可能被阳奉阴违）             │
│            【再议】退回内阁重拟（拖延，但可能拿到更好方案）      │
│            【留中】不批（大臣会骂你，但你有你的理由）           │
│      ↓                                                       │
│  ④ 召对    用剩余精力召见 0～3 人（阁臣/部院/边将/宦官）        │
│            这是你唯一能"听真话"的渠道，也是最贵的              │
│      ↓                                                       │
│  ⑤ 结算    隐藏变量演算：钱粮、民心、军备、官场、派系、天灾     │
│      ↓                                                       │
│  ⑥ 奏报    下个月你看到的，是这次结算的"奏报版"，不是真相       │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

一回合大概 5～15 分钟。一年十二回合。一局目标：在位 48 年（到万历四十八年，1620）。

> 你当然可以选择"不批"。历史上你后来选了这条路——三十年不上朝，帝国居然还转了很久。这也是一种玩法，只是账单会在三十年后一起送到。

## 5. 五个核心机制（深入）

### 5.1 奏报失真 —— 本作最重要的机制

每一个国情数值都有两层：

```
真实值 truth ∈ [0, 100]
奏报值 report = truth ± error
error = f(官员操守, 考成压力, 层级数, 派系立场, 你的情报渠道)
```

具体规则：

| 变量 | 失真来源 | 方向 |
|---|---|---|
| 田亩数 | 清丈官员怕激起民变 → 少报 | report > truth（虚报完成） |
| 赋税收数 | 考成法压得紧 → 州县挪新补旧 | report > truth（旧欠未清而报完） |
| 边镇兵额 | 吃空饷 | report > truth（至少虚报两成） |
| 灾情 | 地方怕考成 → 匿灾不报 | report < truth（灾害被隐瞒） |
| 民变苗头 | 报上去要担责 → 压着不报 | report < truth（直到爆发） |

**关键设计**：失真不是随机的噪音，是**有动机、有方向的偏差**。玩久了你会开始本能地问："这条是好消息，那么谁从这条好消息里得利？"

**你怎么破？** 三条路：
1. **召对**——直接问人，但对方也有立场
2. **另开渠道**——东厂、巡按御史、密奏。代价是得罪官僚系统
3. **自己派人下去查**——最贵，最准，但那个人回来之后可能已经不是原来那个人了

> 这就是为什么"信任的人"是本作的核心资产：**你需要的不是能力最强的人，是你敢信的人。而这两者往往不是同一个人。**

### 5.2 文书四式 —— 你的全部权力

| 动作 | 效果 | 代价 |
|---|---|---|
| **批红·依拟** | 按内阁票拟执行 | 无。但内阁会逐渐把你的意志"格式化" |
| **批红·改拟** | 按你的意思执行 | 越级改拟会被视为"不信任内阁"，多次后会引发辞呈潮 |
| **批红·再议** | 退回重拟 | 拖延一个月，可能拿到更好的方案，也可能被敷衍 |
| **留中** | 不批不发 | 无成本，但每一本留中都在累积"壅滞"，且言官会骂 |
| **召对** | 听一个人说 15 分钟 | 消耗精力；召见谁，谁的身价就涨，其他人就恨 |
| **廷推** | 从三个人里选一个 | 三人是别人挑的，不是你挑的 |
| **特旨** | 绕过内阁直接下令 | 会执行，但执行到什么程度看人；大臣会记仇 |

**核心张力**：你越想亲自控制，壅滞越严重；你越放权，失真越严重。**这两者之间没有正确答案，只有适合你的那个平衡点。**

### 5.3 事项（Project）—— "投入资源、安排人、拿结果"的具象

这是本作的主菜。每一个重大举措是一个**事项**，不是一栋建筑。

```ts
interface Project {
  id: string;
  name: string;             // "清丈天下田亩"
  goal: string;             // 目标描述
  steward: string;          // 承办人（官员 id）—— 最关键的一个字段
  deputies: string[];       // 协办
  budget: number;           // 预算（两）
  spent: number;            // 已支
  deadline: number;         // 期限（月）
  progress: number;         // 【真实】进度 0-100
  reported: number;         // 【奏报】进度 0-100
  resistance: number;       // 阻力（既得利益者的反扑强度）
  sideEffects: SideEffect[];// 副作用：扰民、激起民变、得罪某派
  status: 'planning'|'running'|'stalled'|'done'|'failed'|'scandal';
}
```

**进度演算（每月）：**

```
progress += base_rate
          × steward.competence        // 承办人能力
          × steward.integrity         // 操守（贪则钱花光人不动）
          × (budget_adequacy)         // 钱够不够
          × (1 - resistance/100)      // 阻力
          × (1 - 你的干涉次数 × 0.05)  // 你越插手越慢（重要！）
```

**奏报进度：**

```
reported += progress增量 × steward.honesty_bias
          + steward.考成压力 × 虚报倾向
```

于是会出现这种情况：**事项报了 85%，实际只有 40%。你验收的时候才发现钱花光了、人得罪遍了、事没办成。**

而这时候你能怎么办？办他。但他的门生故吏遍布六科，下一本弹章就是冲你来的。

**历史上的参考答案**：
- 清丈田亩（万历八年—十一年）：办成了，新增田地 82.8 万顷。但张居正死后被全面反攻倒算
- 一条鞭法（万历九年）：办成了，改变了中国财政的底层结构
- 考成法（万历元年）：办成了，然后被申时行废掉

**这就是本作最好的教学**：一个正确的改革，可能因为办事的人倒了而全部作废。

### 5.4 三本账 —— 明代财政的真实结构

| 账 | 归属 | 用途 | 你的权限 |
|---|---|---|---|
| **太仓银库** | 户部 | 百官俸禄、九边年例、宗禄、赈灾 | 理论上你要户部题本才能动。实际上你经常直接"取" |
| **内承运库（内帑）** | 皇帝私房 | 宫廷用度、赏赐、你的私房钱 | 你随便动。但动了就没退路 |
| **太仆寺马价银** | 兵部系统 | 马政、边饷 | 名义上不归你，但历史上你括取殆尽 |

**三本账之间的挪借，是这个游戏最真实的政治。** 户部尚书会跪在文华门外哭着说太仓没钱了；而你昨天刚下旨从太仓提了二十万两去修慈宁宫。

内帑是"最后的钱"。花内帑，大臣会赞你节用；但内帑见底之后，你连赏人都拿不出东西。万历后期"矿税"就是这么被逼出来的——**这是给玩家的一个真实的、可以理解的、但仍然错误的选项。**

### 5.5 考成 —— 玩家自建的管理制度

这是本作的元机制，也是它区别于所有皇帝游戏的地方：**你可以自己设计一套让百官替你干活的规则。**

考成法在开局时是**已存在且在运行**的。它的规则是：

1. 每件事都要立**程限**（期限）
2. 立**三本账簿**：本衙门底册、六科备注册、内阁查考册
3. 每月注销已完事项，每半年通查
4. **征赋不足九成者，一律处罚**（万历四年定）
5. 内阁通过六科，六科通过六部，六部通过抚按

**游戏把它变成一个可调的政策仪表盘：**

| 参数 | 区间 | 效果 |
|---|---|---|
| 征收达标线 | 70% ～ 100% | 高 → 太仓充盈，但州县敲扑小民，民心跌，民变概率涨 |
| 处罚烈度 | 罚俸 / 降级 / 革职 / 廷杖 | 高 → 执行力强，但官员只会报喜不报忧，失真加剧 |
| 账簿核查频次 | 半年 / 季 / 月 | 高 → 你能看到更多真相，但行政成本高，官员怨声载道 |
| 内阁查考权 | 有 / 无 | 有 → 政令畅通；无 → 内阁虚设，六部各行其是 |

**这个仪表盘没有最优解。** 调到最严，你会得到一个高效但满目疮痍的帝国；调到最松，你会得到一个安静但正在腐烂的帝国。

历史给出的答案是：张居正调到最严，干了十年，人一死，全部推翻。你可以选择走他的路，也可以选择走申时行的路（"一切为简易"，收买人心，然后眼看着帝国慢慢松掉）。

**这是本作最想问你的一句话：你能给这个帝国留下的，是一个能自我运转的制度，还是一个离不开你的系统？**

## 7. 界面结构

不用"宫殿地图"。你不需要"去"太和殿，你需要的是**案头**。

```

├────────────┬─────────────────────────────────────────────┤
│            │                                             │
│  通 政 司   │   奏疏列表（可排序：紧急/部院/地方/弹章）      │

│  已批 216  │   │                                    │     │
│            │   │ [依拟] [改拟] [再议] [留中]         │     │
│  ────────  │   └───────────────────────────────────┘     │

├────────────┴─────────────────────────────────────────────┤

│        实况 ？？？  （你只能看到奏报）                     │
└──────────────────────────────────────────────────────────┘
```

**三条界面原则：**

1. **一切以文书呈现，不以"面板"呈现。** 国库不是进度条，是户部的一本奏疏；兵额不是一个数字，是兵部的一本册子。
2. **真实值绝不直接显示。** 除了内帑（你自己的钱袋），所有数字都标"奏报"。
3. **字要能读。** 奏疏正文用真文本，仿宋，竖排可选。这是本作的审美基底——你不是在玩数值，你是在读一个帝国的来信。

## 8. 技术方案

| 项 | 选型 | 理由 |
|---|---|---|
| 构建 | Vite + TypeScript | 快，型别安全，适合长期迭代 |
| UI | React 18 + 少量 CSS 变量 | 文本密集型界面，React 的组件化最省事 |
| 状态 | Zustand（或自写 reducer） | 单一大 world state，纯函数结算 |
| 存档 | localStorage + JSON 导入导出 | 无后端，纯前端，可离线 |
| 数据 | `src/data/*.ts` 全部内容数据化 | 事件、官员、政策、奏疏模板与逻辑分离 |
| 测试 | Vitest，重点测结算纯函数 | 数值是可测的，别靠手感 |
| 目录 | 见下 | |

```
C:\Users\Administrator\Projects\pihong\
├─ docs\            设计文档、史料摘录
├─ src\
│  ├─ engine\       纯逻辑：结算器、失真器、事项、人事
```

## 9. 里程碑

### M0 —— 能玩的一小时（先做这个）

目标：**跑通一个完整回合，感受到"奏报不等于真相"。**

范围刻意缩小：
- 只有一本账（太仓）
- 只有 3 个官员
- 只有 1 个事项（清丈田亩）
- 只有 12 条开局奏疏
- 没有派系、没有军务、没有灾荒

但核心机制必须完整：**批红四式 + 精力限制 + 留中壅滞 + 事项的真实/奏报双轨**。

## 10. 风险与待定项

**风险**

1. **变成数学游戏**：双轨数值一旦被玩家算穿，乐趣就没了。对策：定期改变失真规则，让玩家永远只能"估"。
2. **文本量爆炸**：奏疏要像人写的。对策：模板 + 变量 + 语料库，先做 50 条高质量的，比 500 条平庸的有用。
3. **首版太薄**：M0 只有 12 条奏疏，一小时就见底。对策：M0 明确标注"技术验证版"，不追求耐玩。
4. **考成仪表盘太抽象**：玩家可能不知道调它有什么用。对策：必须有即时的、可感的反馈（"你把达标线从九成提到十成，山东有 17 名知县降级"）。

**待你拍板**

1. **技术形态**：浏览器网页（推荐，立刻能玩、能改、能打包）还是别的？
2. **开局年份**：万历十年（推荐）还是别的时点（嘉靖三十九年严嵩当国 / 隆庆元年 / 天启年间魏忠贤）？
3. **首版深度**：先做 M0 技术验证（快，粗），还是直接冲 M1（慢，完整）？
4. **审美取向**：仿古文书风（竖排、朱批、纸色）还是现代深色数据风？
