# 批红 · 万历十年

一款明代历史策略模拟游戏。你扮演十九岁亲政的万历皇帝，只有三件事可做：**批红、用人、立规矩**。

> 所有数字都是奏报值，不是真值。
> 你派出去的人，回话也未必是真的。

---

## 为什么要做这个

多数帝王游戏让你无所不能：钱、人心、军队，点一下就有。

这一作反过来——**稀缺的是注意力**。一年三十六旬、每旬八点精力，天下的奏疏你看不完。你能做的只有：

| 手段 | 管什么 |
|---|---|
| **批红** | 管一件事。依拟、改拟、还是留中 |
| **用人** | 管一个人。而你不知道谁行 |
| **立规矩** | 改国运。法一立，往后每一旬它都在暗处用力 |

## 三条核心机制

### 一、认知，而不是数值

官员的能力不显示。你只看到「才具似在中上」「操守未有所闻」这种模糊判断，靠四条通道攒线索：

- **召对**（2 精力）：选话题一问一答。他会藏，但你能看出他藏
- **派差**：看他办得怎么样，最准也最慢
- **人言**：同党夸他、异党骂他，每句话都带着说话人的位置
- **东厂 / 锦衣卫**（2 万 / 3 万内帑）：一个便宜但虚，一个贵但实，都可能被买通

线索攒在同一本账上，会互相矛盾——于是官员卡上写「众说纷纭」，而你要自己判断是哪个环节出了问题。

结局时翻底牌：**你当年怎么看这个人，他实际如何。**

### 二、律令改变国家走向

六条法：考成法、一条鞭、开海、宗禄折色、矿税、廷杖言官。每条都有明确的反对者，立了会长出后续奏疏——

- 废考成 → 户部来报逋欠翻倍
- 开矿税 → 湖广来报民聚数千
- 行一条鞭 → 江南士绅联名请减，署名的二百四十七人里十九个是首辅的门生

### 三、批完才开始

急件与事项批下去会**交办**给具体的人：

```
干才决定办得快慢 → 廉洁决定他报的数有多虚 → 到期回话「已办竣」 → 你可遣人核实
```

核出来的常对不上。对了，是「此人还算实心办事」；错了，他声望掉、考语改写、官风降。

## 五年，一百八十旬

万历十年六月（1582）起，铺到万历十五年。

张居正身后事、考成法存废、京察、清丈收尾、建州起兵、国本之争，按年推进。**后面的事件真的依赖你前面的选择**——不夺张居正的爵，就没有抄家那一本；京察没加严，就没有顾宪成鸣冤。

## 怎么玩

**直接下载**：到 [Releases](../../releases) 下载 `pihong.html`，双击用浏览器打开。

单文件，不需要联网、不需要服务器、不需要安装。手机上也能玩（同一文件，自适应布局）。

**本地开发**：

```bash
npm install
npm run dev      # http://127.0.0.1:5273
npm test         # 82 个测试
npm run build    # 产出单文件 dist/index.html
```

## 技术

React 19 + Vite + TypeScript（strict）+ Vitest。构建产物是单个内联 HTML，无外部依赖。

## 目录

```
src/
  engine/
    tick.ts        旬推进
    knowledge.ts   认知账本（估计 / 确信 / 来源 / 空白）
    orders.ts      政令：交办 → 承办 → 回话 → 核实
    sender.ts      具奏人署名（衙门简称补成正式职名）
    inner.ts       内廷：代批、缉访、打探
    actions.ts     批红、召对、罢免、密谕
  data/
    memorials/     74 种奏疏，按年份与叙事线分文件
    statutes.ts    六条律令及其持续效果
    speech.ts      召对问答（五种说话样式）
    backgrounds.ts 每本奏疏的「缘起」
  ui/              界面
docs/
  设计-认知系统.md
```

## 怎么加一条奏疏

```ts
export const myEvent = def(
  'my-event',
  'urgent',                                   // routine | urgent | project | personnel | impeach
  (s) => ({
    from: '河南巡抚',
    title: '为黄河决口、请发帑金事',
    summary: '一句提要，不细看也能看到。',
    body: `臣谨奏：……\n\n伏乞圣裁。`,
    piaoni: '工部看议。',
    yiEffect: { taicang: -5 },
    patience: 3,
    options: [
      {
        key: 'quan',
        label: '全给十五万，即日兴工',
        needsReading: true,                   // 必须先花精力细看
        note: '一句小字提示，不写效果。',
        effect: { ledger: { taicang: -15 }, metric: { minxin: 3 } },
      },
    ],
  }),
  { weight: 0, cooldown: 999, line: 'my-line', when: (s) => s.turn >= 40 },
)
```

再把它加进 `src/data/memorials/index.ts` 的 `ALL` 数组，并在 `backgrounds.ts` 里补一段缘起。

`Effect` 可改：`taicang / neitang / taipu`、`metrics`（或 `metric`）、`ledger`、`project`、`power`、`frontier`、`appoint`、`policy`、`statutes`、`flags`、`spawn`、`backlog`。

## 已知的不足

- 五年内的奏疏种类还不够多（74 种，目标 100—120）
- 党争目前影响廷推名单与声望，尚未做成完整的结党玩法
- 存档存在本机浏览器，换文件地址等于换存档

## 史料

财政数字取自张居正《看详户部进呈揭帖疏》与《明史纪事本末》卷六十一。

冯保籍家得银「百余万」，张居正籍家得银「十万七千七百余两」——这个反差是史实，也是本作把「抄家的钱」按廉洁程度算的原因。
